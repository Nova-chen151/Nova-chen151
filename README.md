## 👋 About Me

你好，我目前在 **同济大学交通运输工程学院 TOPS 交通运行与仿真课题组** 开展研究。我的研究关注 **自动驾驶场景生成、多智能体行为仿真与闭环仿真测试**，希望让真实驾驶数据与生成模型共同服务于驾驶策略的训练、测试和改进。
